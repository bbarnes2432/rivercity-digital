# Website-design inquiry recovery — September 18, 2026

The owner authorized the September 18 recovery recommendations and explicitly required keeping the telephone option. This release puts the advertised free mockup beside a short form and real work, retaining calls in the hero, header, contact section and mobile bar. It does not introduce staff identities, photos, promised turnaround times or fabricated results.

## Page and measurement

- One existing form: alongside the offer on desktop, early in the mobile flow. Name and email remain the only required visitor fields; phone and project context are optional.
- Real client work and the existing attributed testimonial remain prominent. Technical comparison/software content is retained in an expandable section. Existing technical fragment links automatically expand it.
- Decorative WebGL/cursor/reveal components are removed from this paid page. Other routes retain their established presentation.
- `mockup-recovery-2026-09-18` identifies this version. Same-origin `/api/funnel` records allowlisted view, start, validation, submit, error, acceptance and CTA events in private hosting runtime logs as `rcd_funnel`. A random tab-session ID links stages. No form values, full URLs, click IDs or arbitrary properties are included. Optional browser events honor DNT/GPC and fail independently of delivery.
- Client events are untrusted diagnostics, never evidence of an actual inquiry. Call taps remain secondary in Ads; no funnel event becomes an Ads conversion.
- `/api/contact` logs `rcd_delivery` records: configuration error, provider request/rejection/acceptance, or unconfirmed timeout/network response. The accepted receipt UUID is returned to the form and reused for conversion deduplication. A Resend message ID stays in private runtime logs when available.
- **Provider acceptance does not prove inbox delivery.** Resend historical delivery/bounce records and automatic delivered/bounced callbacks still need access to the existing Resend account and hosting configuration. This release does not claim to install a bounce webhook or diagnose historical inbox loss.
- Privacy copy describes the diagnostic data. Honeypot responses explicitly carry `ignored: true`; all five form clients exclude these and local previews from primary conversion events.

## Reading outcomes

Filter the existing hosting runtime logs for the JSON `kind` values `rcd_funnel` and `rcd_delivery`. Group browser stages by session and page version; reconcile accepted browser events with server receipt IDs. Use the server's provider ID to inspect delivered/bounced status in Resend. Logs are an operational diagnostic, not a complete analytics dashboard or permanent lead database. Hosting retention and production log access must be confirmed by the hosting owner. Old visits cannot be reconstructed.

Compare qualified inquiries and spend over complete account-timezone days with the prior period. This rollout also restores Ads search matching; the combined rollout is not a randomized test that isolates website lift. Low traffic and conversion delay limit conclusions. Do not increase budget or expand geography on the strength of a few visits.

## Verification

- 148 isolated mocked checks: 20 observability, 42 lead routes, 55 conversion handoffs, 16 enhanced conversion, 8 call forwarding and 7 entry attribution checks. No real email, call or primary conversion was sent by these tests.
- Full lint, TypeScript/build and whitespace checks passed.
- Local production browser checks at 1280, 390 and 320 CSS pixels: one form, usable inputs, no horizontal overflow, retained telephone destinations, native validation, failure fallback, project preview, working fragment navigation and mobile menu. No captured JS warnings/errors in the final check.
- At 390 pixels the form heading is about document Y728 instead of Y22,787; the default page height is about 7,417 instead of 24,869 pixels. These are layout observations, not measured conversion gains. The old form shortcut already worked.
- Local failure testing used an explicitly empty Resend key. No production synthetic lead or telephone call was authorized or sent.

The agency change record contains the publication SHA, public verification, comparable performance measurements and final Ads/CHEQ status. Rollback is a reviewed git revert of this website release; no secrets are stored in this document.
