# New River City logo (river mark)

User request (2026-09-28): replace the logo with the supplied design ("RIVER CITY", a teal river "S" mark, "DIGITAL", and the tagline "LOCAL ROOTS. BUILT TO BE FOUND."), with the black background removed and vectorized.

The wordmark and tagline are the existing vector glyphs from the previous logo SVG, placed where the supplied image has them (they matched its proportions within about a pixel). Only the river mark was traced from the supplied image (upsampled coverage, potrace), with a linear teal gradient fitted to its colours; the tagline teal is sampled from the image. Traced-against-source overlap: about 95% for the mark and wordmark.

Files keep their names and their 3155 x 510 canvas, with the lettering at the previous size, so every `width`/`height` prop and CSS rule is unchanged: `logo-color.svg/.webp` (white text, teal mark and tagline), `logo-white.svg/.webp` (all white), `logo-black.svg` (navy text), `logo-color-bg.webp` (on navy), and `qc-logo-river.svg` (Quad Cities now uses the same logo). The navigation, drawer and footers now show the colour version (previously all white). `favicon.webp` and `app/favicon.ico` (16–256 px) show the river mark on navy, slightly brightened for legibility at small sizes.

Validation: ESLint, TypeScript and a production build; header, drawer and footer screenshots at 1440 and 390 px on the home, website-design, Chicago, Quad Cities and about pages.
